JavaScript Fundamentals

Foundational theory for understanding the JavaScript language, its environment and its role in modern web development.

Course Overview

JavaScript Fundamentals introduces the concepts and principles that form the foundation of programming with JavaScript. The course explains what the language is, how it operates, and how its main features are used to create interactive and dynamic applications.

General Aim

To provide learners with a clear theoretical understanding of JavaScript and the fundamental programming concepts used when developing web applications.

Learning Outcomes

By the end of this unit, learners should be able to:

  • Define JavaScript and explain its purpose in software and web development.
  • Describe the characteristics and common uses of JavaScript.
  • Explain the relationship between HTML, CSS and JavaScript.
  • Identify the main parts of JavaScript syntax and program structure.
  • Explain variables, constants, data types and operators.
  • Describe decision-making structures, loops and functions.
  • Identify common categories of programming errors and explain debugging.

1. Introduction to JavaScript

Definition

JavaScript is a high-level, general-purpose programming language commonly used to make websites and web applications interactive and dynamic. It can also be used outside the browser, including on servers and in other software environments.

Purpose of JavaScript

JavaScript enables a program to respond to events and perform actions based on user input or changing information. It can update page content, validate form entries, respond to button clicks, display messages, retrieve information from servers and control application behaviour.

Brief History

JavaScript was created by Brendan Eich in 1995 while he was working at Netscape. It was initially developed to add programming capabilities to web pages. The language later became widely adopted and standardized through a specification known as ECMAScript.

JavaScript and ECMAScript

ECMAScript is the standardized specification that defines the core rules and features of the language. JavaScript is the widely used implementation of that specification. The specification helps different JavaScript environments support a consistent language.

Important distinctionJavaScript and Java are separate programming languages. Their similar names do not mean that they are the same language or that one is a version of the other.

2. Characteristics of JavaScript

High-level language

JavaScript provides language features that allow programmers to work with understandable instructions and data structures without manually managing most low-level computer operations.

Interpreted and just-in-time compiled execution

JavaScript is commonly described as an interpreted language because developers can run it without manually compiling a separate executable first. Modern engines may also compile parts of the code during execution to improve performance.

Dynamically typed

A variable does not need a fixed data type declaration. The type is associated with the value currently held by the variable, and that value can change to another type during execution.

Event-driven

JavaScript can respond to events such as mouse clicks, keyboard input, form submission and page loading. An event is an action or occurrence that a program can detect and respond to.

Multi-paradigm

JavaScript supports different programming approaches, including procedural, object-oriented and functional programming. A programming paradigm is a general style or approach to organizing and writing programs.

Cross-platform

JavaScript is supported by modern web browsers and several server-side and application environments. This allows JavaScript programs to run on different operating systems and devices when a compatible runtime is available.

Case-sensitive

JavaScript distinguishes between uppercase and lowercase letters. For example, total, Total and TOTAL are treated as different identifiers.

3. JavaScript Environments and Execution

JavaScript Engine

A JavaScript engine is software that reads, processes and executes JavaScript code. It translates the language instructions into operations the computer can perform. Different browsers use different engines.

Runtime Environment

A runtime environment provides the facilities needed to execute JavaScript. It includes the JavaScript engine and additional features, often called APIs (Application Programming Interfaces), that allow code to interact with its surroundings.

Browser Environment

When JavaScript runs in a browser, it can work with browser-provided features. These include the Document Object Model (DOM), browser events, timers and network communication facilities.

Server-side Environment

JavaScript can also run outside a browser. Node.js is a JavaScript runtime environment that allows developers to build server-side applications, work with files, communicate over networks and create backend services.

Engine versus runtimeThe engine executes JavaScript language instructions. The runtime provides the engine together with additional tools and APIs that make the environment useful for a particular purpose.

4. Relationship Between HTML, CSS and JavaScript

HTML, CSS and JavaScript are three different technologies that commonly work together to build websites.

HTML — Structure

HyperText Markup Language (HTML) defines the structure and content of a web page. It identifies elements such as headings, paragraphs, images, links, forms and buttons.

CSS — Presentation

Cascading Style Sheets (CSS) control the appearance and layout of a web page. CSS is used for colours, fonts, spacing, positioning, responsive layouts and visual effects.

JavaScript — Behaviour

JavaScript controls behaviour and interaction. It can respond to user actions, change page content, update styles and communicate with external services.

How they work together

HTML provides the page structure, CSS controls its presentation, and JavaScript adds behaviour. Together, they form the core frontend technologies used in web development.

5. JavaScript Syntax and Program Structure

Syntax

Syntax refers to the rules that determine how instructions must be written in a programming language. JavaScript code must follow its syntax rules to be understood correctly by the engine.

Statements

A statement is an instruction that performs an action. A JavaScript program is generally made up of statements that are executed according to the program's control flow.

Expressions

An expression is a combination of values, variables and operators that produces a value. Expressions can be used inside statements and other expressions.

Comments

Comments are notes written in source code for people reading or maintaining the program. They are ignored during normal program execution. JavaScript supports single-line comments and multi-line comments.

Identifiers

An identifier is a name given to a program element, such as a variable or function. Identifiers must follow naming rules: they cannot begin with a number, cannot contain spaces and cannot be reserved keywords. Names are case-sensitive.

Semicolons and Code Blocks

Semicolons can mark the end of statements. JavaScript also has automatic semicolon insertion, but using semicolons consistently can make code boundaries clearer. Curly braces { } group statements into a code block, such as the body of a function or condition.

6. Variables and Constants

Variable

A variable is a named storage location used by a program to hold a value that can be accessed and, where permitted, changed during execution.

Constant

A constant is a named binding that cannot be reassigned after it has been initialized. The value of an object or array declared with a constant may still have its contents changed.

Variable Declaration Keywords

JavaScript provides three commonly discussed keywords for declaring variables:

  • let: declares a variable that can be reassigned. It is block-scoped, meaning it is available within the block in which it is declared.
  • const: declares a binding that cannot be reassigned. It is also block-scoped and must be initialized when declared.
  • var: declares a function-scoped or globally scoped variable. It has older scoping behaviour and is generally less preferred in modern JavaScript.

Variable Naming Rules

  • A name may contain letters, digits, underscores and dollar signs.
  • A name cannot begin with a digit.
  • Spaces are not allowed in identifiers.
  • Reserved keywords cannot be used as variable names.
  • Names are case-sensitive.
  • Descriptive names make programs easier to understand and maintain.

Scope

Scope determines where a variable or other identifier can be accessed in a program. Common forms include global scope, function scope and block scope. Understanding scope helps prevent naming conflicts and unintended access to data.

7. JavaScript Data Types

Data type

A data type identifies the kind of value a program is working with and influences the operations that can be performed on that value.

JavaScript data types are commonly grouped into primitive types and non-primitive types.

Primitive Data Types

  • String: represents text, such as names, messages and other character data.
  • Number: represents numeric values, including integers and decimal numbers.
  • BigInt: represents integers larger than the range safely represented by the ordinary Number type.
  • Boolean: represents one of two logical values: true or false.
  • Undefined: represents a value that has not been assigned to a declared variable or is otherwise missing.
  • Null: represents the intentional absence of an object value.
  • Symbol: represents a unique value often used as a distinctive property key.

Non-primitive Data Type

Object: an object is a collection of related data and functionality represented through properties. Arrays and functions are also objects in JavaScript, although they have specialized behaviour.

Dynamic Typing

JavaScript is dynamically typed because a variable can hold values of different types at different points in a program. The type belongs to the value rather than being permanently fixed to the variable.

8. Operators and Expressions

Operator

An operator is a symbol or keyword that performs an operation on one or more values. The values an operator acts on are called operands.

Arithmetic Operators

Arithmetic operators perform mathematical calculations. Common examples include addition, subtraction, multiplication, division, remainder and exponentiation.

Assignment Operators

Assignment operators assign values to variables. The basic assignment operator is =. Compound assignment operators combine an operation with assignment.

Comparison Operators

Comparison operators compare values and produce a Boolean result. Examples include equal value, equal value and equal type, not equal, greater than and less than.

The strict equality operator === checks both value and type, while == may convert values before comparing them.

Logical Operators

Logical operators combine or reverse logical conditions. The main operators are AND (&&), OR (||) and NOT (!).

Other Operators

JavaScript also provides operators such as the conditional (ternary) operator, the type-checking typeof operator and the nullish coalescing operator. Each serves a particular purpose when evaluating values or conditions.

9. Control Structures

Control structure

A control structure determines the order in which instructions in a program are executed. It allows a program to make decisions, repeat instructions or follow a particular sequence.

Sequence

Sequence is the normal flow in which instructions are executed one after another, in the order in which they appear, unless another control structure changes that flow.

Selection or Decision-making

Selection structures allow a program to choose which instructions to execute based on whether a condition is true or false.

  • if: executes a block when a condition is true.
  • if...else: selects between two possible paths.
  • else if: checks additional conditions when earlier conditions are false.
  • switch: selects a block from several possible cases based on an expression's value.

Iteration or Loops

Iteration means repeating a block of instructions. Loops reduce unnecessary repetition and are useful when an action must be performed multiple times.

  • for loop: commonly used when the number of repetitions or the loop progression is known.
  • while loop: repeats while a condition remains true.
  • do...while loop: executes its block at least once before checking the condition.
  • for...of loop: iterates over values from an iterable, such as an array or string.
  • for...in loop: iterates over enumerable property names of an object.

Loop Control Statements

break terminates a loop or switch structure. continue skips the remaining instructions in the current loop iteration and proceeds to the next iteration where applicable.

10. Functions

Definition

A function is a reusable block of code designed to perform a particular task. It can be called whenever that task needs to be performed.

Purpose of Functions

  • Reduce repeated code.
  • Divide a large program into smaller manageable parts.
  • Improve organization and readability.
  • Make code easier to test, maintain and reuse.

Parameters and Arguments

A parameter is a named variable listed in a function definition to receive input. An argument is the actual value supplied when the function is called.

Return Value

A return value is the result a function sends back to the part of the program that called it. The return statement ends the function's current execution and can provide that result.

Common Forms of Functions

  • Function declaration: a named function defined using the function keyword.
  • Function expression: a function created as part of an expression and commonly assigned to a variable.
  • Arrow function: a shorter function syntax introduced in modern JavaScript. Arrow functions have different rules for handling their own this value compared with traditional functions.
  • Anonymous function: a function without its own declared name, often used where a function value is needed temporarily.

11. Errors and Debugging

Programming error

An error is a problem in a program that may prevent it from running correctly or cause it to produce an unintended result.

Syntax Errors

A syntax error occurs when code violates the language's writing rules. The JavaScript engine cannot correctly parse the affected code.

Runtime Errors

A runtime error occurs while a program is executing. The code may have been accepted syntactically, but an operation fails during execution.

Logical Errors

A logical error occurs when a program runs but produces an incorrect result because its instructions or reasoning do not achieve the intended outcome.

Debugging

Debugging is the process of finding, understanding and correcting errors in a program. It may involve reading error messages, inspecting values, following program execution and testing corrections.

Common Debugging Tools

Browser developer tools provide facilities such as the console, debugger, breakpoints and inspection panels. These tools help developers observe program behaviour and investigate problems.

12. Summary of Key Concepts

  • JavaScript is a programming language used to create interactive and dynamic applications.
  • ECMAScript is the standard specification on which JavaScript is based.
  • A JavaScript engine executes JavaScript code, while a runtime provides the engine and additional capabilities.
  • HTML defines structure, CSS controls presentation and JavaScript provides behaviour.
  • Syntax defines the rules for writing valid instructions.
  • Variables hold values; constants prevent reassignment of their bindings.
  • Data types describe the kinds of values handled by a program.
  • Operators perform operations on values.
  • Control structures determine the flow of execution.
  • Functions organize reusable instructions into manageable units.
  • Debugging helps identify and correct program errors.
