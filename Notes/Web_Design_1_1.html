Web Design 1.1

An introduction to the principles used to plan, organise and present websites. These notes cover design purpose, layout, colour, typography, navigation, usability, responsiveness and accessibility.

SUBJECT: WEB DESIGNLEVEL: FOUNDATIONALFORMAT: THEORY NOTES

Course Overview

Web design is the process of planning how a website looks, how information is arranged and how visitors move through and use its pages. Good design makes information clear, consistent, accessible and easy to use.

General Aim

To introduce the principles and elements of web design and explain how they contribute to a usable and effective website.

Learning Outcomes

  • Define web design and explain its purpose.
  • Distinguish web design from web development.
  • Identify the main elements and principles of visual design.
  • Explain layout, spacing, colour, typography and navigation.
  • Describe responsive design, usability and accessibility.
  • Explain the importance of planning and testing a website design.

1. Meaning and Purpose of Web Design

Web design

Web design is the planning and creation of the visual appearance, layout, structure and user experience of a website. It determines how content is presented and how users interact with the interface.

The purpose of web design is not simply to make a website attractive. It should help visitors understand information, find what they need, complete tasks and use the website comfortably on different devices.

Web Design versus Web Development

Web design focuses on presentation, organisation and user experience. Web development implements the design using technologies such as HTML, CSS and JavaScript. Both activities work together to produce a complete website.

2. Elements of Web Design

Layout

The arrangement of headings, text, images, navigation and other elements on a page.

Colour

Colour creates visual identity, communicates meaning and helps distinguish important interface elements.

Typography

The selection and arrangement of fonts, sizes, weights, line spacing and text hierarchy.

Images and graphics

Visual material that supports meaning, explains information and strengthens presentation.

Whitespace

Empty space around elements that improves readability, grouping and visual balance.

Navigation

Menus, links and controls that help visitors move between pages and sections.

3. Principles of Good Web Design

Consistency

Related pages should use familiar colours, typography, spacing and navigation patterns. Consistency helps users learn the interface.

Visual hierarchy

Important information should be more noticeable through size, position, contrast, spacing and emphasis. A clear hierarchy guides the visitor's attention.

Balance and alignment

Balance distributes visual weight across a page. Alignment places related elements along clear visual lines, making the design feel organised.

Contrast

Contrast creates visible differences between elements. It can distinguish headings from body text and make buttons easier to identify. Text must still have sufficient contrast against its background.

Simplicity

A simple interface avoids unnecessary decoration and controls. Each element should support the website's purpose or help the user complete a task.

Proximity

Elements that belong together should be placed close to one another. This helps users understand relationships between labels, fields, images and descriptions.

4. Website Layout and Structure

A layout defines where content and interface elements appear. A common website page contains:

  • Header: the top area, often containing a logo, site name and navigation.
  • Navigation: links that lead to important pages or sections.
  • Hero section: a prominent introductory area that communicates the page's main message.
  • Main content: the primary information or functionality of the page.
  • Sidebar: optional supporting content or secondary navigation.
  • Footer: the bottom area, commonly containing contact details, policies and secondary links.
ImportantNot every website needs a sidebar or a large hero section. The layout should be selected according to the website's content, audience and purpose.

5. Colour and Typography

Colour schemes

A colour scheme is a planned group of colours used throughout a website. A design may use a primary colour for identity, secondary colours for supporting elements, an accent colour for important actions and neutral colours for backgrounds and text.

Common colour relationships include monochromatic schemes, analogous schemes and complementary schemes. Colour should be used consistently and should not be the only way of communicating important information.

Typography

Typography affects readability and the character of a website. A useful type system defines heading sizes, body text, font weights, line height and spacing. Limit the number of font families and maintain readable text sizes.

6. Navigation and User Experience

User Experience (UX)

User Experience describes the overall experience a person has when interacting with a website or product, including how easy, clear, efficient and satisfying it is to use.

Navigation should use understandable labels and predictable placement. Visitors should be able to identify where they are, where they can go and how to return to important sections.

Usability

Usability is the degree to which users can achieve their goals effectively, efficiently and with satisfaction. Clear instructions, useful feedback, readable content and predictable controls improve usability.

7. Responsive Web Design

Responsive web design

Responsive web design is an approach in which a website's layout and content adapt to different screen sizes and device capabilities.

A responsive website should remain usable on mobile phones, tablets, laptops and desktop screens. Developers commonly use flexible layouts, relative units, flexible images and CSS media queries to achieve this.

Mobile-first design

Mobile-first design begins with the constraints of smaller screens, then progressively enhances the layout for larger screens. It encourages designers to prioritise essential content and functionality.

8. Accessibility in Web Design

Web accessibility

Web accessibility means designing and building websites so that people with different abilities can perceive, understand, navigate and interact with the content.

  • Use meaningful headings in a logical order.
  • Provide descriptive alternative text for informative images.
  • Use readable text and sufficient colour contrast.
  • Ensure interactive controls can be used with a keyboard.
  • Give form fields clear labels and useful error messages.
  • Do not rely on colour alone to communicate meaning.

9. The Web Design Process

  1. Understand the purpose: identify the website's goals and intended users.
  2. Gather requirements: determine the content, features and tasks the website must support.
  3. Plan the structure: organise pages and create a sitemap.
  4. Create wireframes: sketch the placement of content and interface elements before detailed styling.
  5. Develop the visual design: select colours, typography, spacing, imagery and reusable components.
  6. Build the interface: implement the design using HTML, CSS and, where needed, JavaScript.
  7. Test and improve: check usability, accessibility, responsiveness and consistency on different devices.

10. Summary of Key Concepts

  • Web design plans a website's appearance, layout, navigation and user experience.
  • Layout, colour, typography, imagery, whitespace and navigation are major design elements.
  • Consistency, hierarchy, balance, alignment, contrast, simplicity and proximity are important design principles.
  • Responsive design helps websites adapt to different screens.
  • Accessibility makes websites usable by people with different abilities.
  • Good design begins with understanding the user and the purpose of the website.
